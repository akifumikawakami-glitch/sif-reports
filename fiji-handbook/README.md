## 第0章 はじめに：使い方と「誤解Top10」

### 読み方

| レベル | 対象 | 読む箇所 |
|---|---|---|
| 1分版 | 渡航前の受講者、初めて関わる人 | 本章の「誤解Top10」＋各章冒頭の **30秒サマリ** |
| 10分版 | 案件メンバー、クライアント説明 | 30秒サマリ＋各章の表と太字 |
| 深掘り版 | 現地調査・提案書作成 | 全文＋第10章の一次資料 |

### 日本人が誤解しやすいことTop10

1. **Suvaは本島の東寄りなのに「Central」**。Eastern Division は東の離島群（Lau・Lomaiviti・Kadavu）のこと。群島全体で見ればSuvaは「中央」。→ 第1章
2. **「Fijian」は民族名ではなく国民全体の呼称**（2010年以降）。先住系は **iTaukei（イタウケイ）**、インド系は **Indo-Fijian**。→ 第4章
3. **土地のほとんどは売買できない**。国土の約9割は iTaukei の共同体（mataqali など）が所有し、譲渡不可。使うには **TLTB経由のリース**。→ 第5章
4. **海にも「持ち主」がいる**。沿岸の漁場は **qoliqoli（慣習的漁業権区域）** として共同体に紐づく。→ 第5章
5. **行政は二本立て**。政府ライン（Division／District）と iTaukei ライン（Province／Tikina／Koro）が並走している。→ 第6章
6. **村の「村長」は首長ではない**。Turaga ni Koro は行政上の村代表で、伝統的首長（Ratu など）とは別。→ 第6章
7. **インド系住民の多くはGirmit（年季契約労働）の子孫**で、140年以上の歴史を持つ「フィジー人」。→ 第3章
8. **西と東で気候も産業も気質も違う**。西（Nadi・Lautoka）は乾燥・観光・サトウキビ、東（Suva）は多雨・行政・地域機関。→ 第1章
9. **地名はローマ字読みすると間違える**。Nadi＝「ナンディ」、Beqa＝「ンベンガ」。→ 第2章
10. **クーデターは「過去の話」ではない**。1987年のクーデター指導者が現首相（Rabuka）。政治・民族・土地の話題は慎重に。→ 第3章・第9章

## 第1章 地理と地域性：「地図の読み方」

> **30秒サマリ**：約330の島（有人約110）。本島 Viti Levu と第2の島 Vanua Levu に人口の大半。行政上は4つの Division（Central／Western／Northern／Eastern）に分かれ、「Eastern＝東の離島群」なので、本島南東の Suva が「Central」になる。本島は**東が多雨・西が乾燥**で、これが産業と地域性の違いを生んでいる。

### 1-1 群島の全体像

| 島・島群 | 位置づけ |
|---|---|
| **Viti Levu（ヴィティ・レヴ）** | 本島。面積約1万km²。Suva（首都）、Nadi（国際空港）、Lautoka 等。人口の約4分の3 |
| **Vanua Levu（ヴァヌア・レヴ）** | 第2の島。北部の中心 Labasa、Savusavu。サトウキビと離島的な農村 |
| **Taveuni（タヴェウニ）** | 「ガーデン・アイランド」。日付変更線（180度経線）が通る |
| **Kadavu（カンダヴ）** | 本島の南。Eastern Division に属する |
| **Lomaiviti（ロマイヴィティ）諸島** | Ovalau 島に旧首都 **Levuka**（世界遺産） |
| **Lau（ラウ）諸島** | 最東端。トンガ文化の影響が強い |
| **Yasawa／Mamanuca 諸島** | 本島西沖のリゾート地帯（Western Division） |
| **Rotuma（ロトゥマ）** | 北に約500km離れたポリネシア系の島。独自の言語・文化を持ち、属領（dependency）扱い |

- 陸地面積：約1万8,300km²（四国とほぼ同じ）。EEZは約130万km²と広大。
- 最高峰：Tomanivi（旧名 Mt Victoria）1,324m。本島中央は山地で、**主要道路は海岸沿いの環状道路**（Queens Road＝南回り、Kings Road＝北回り）。

### 1-2 なぜ Suva は「Central」なのか

- 4つの Division は「本島の東西」ではなく「**群島全体の中での位置**」で付けられている。
  - **Central**：本島南東部（Suva・Nausori・Navua 周辺）
  - **Western**：本島西部と西沖の島々（Nadi・Lautoka・Ba・Sigatoka・Rakiraki）
  - **Northern**：Vanua Levu と Taveuni 周辺（Labasa・Savusavu）
  - **Eastern**：東・南の離島群（Lomaiviti・Lau・Kadavu）
- 本島の地図だけを見ると Suva は「東」だが、さらに東に島々が連なるため「中央」になる。**本島の東部＝Central、東の海に浮かぶ島＝Eastern**と覚える。

### 1-3 東西で異なる性格

| | 東（Central側：Suva） | 西（Western側：Nadi・Lautoka） |
|---|---|---|
| 気候 | 南東貿易風が山にぶつかる**風上側で多雨**。年中じめじめ | **風下側で乾燥**。晴天が多く、乾季がはっきり |
| 主な産業 | 行政、国際機関、大学、港湾、サービス | 観光（国際空港・リゾート）、サトウキビ、製糖 |
| 人口構成 | iTaukei と Indo-Fijian が混在する都市 | サトウキビ地帯（Sugar Belt）に **Indo-Fijian が多い** |
| 伝統的権威 | Bau・Rewa など東部の有力首長国の勢力圏 | 東の首長国から距離があり、**独自性・東への対抗意識**が語られる |

- 西部は「国の稼ぎ（観光・砂糖）は西、政治と予算配分は東（Suva）」という不満が語られることがある。西部独自の首長連合構想（Yasayasa Vaka-Ra）が持ち出されたこともある。
- **北（Vanua Levu）**：Labasa はサトウキビ地帯で Indo-Fijian が多い。Savusavu はヨット・移住者の町。全体に「地方」扱いでインフラが遅れがち。
- **東の離島（Lau・Lomaiviti・Kadavu）**：船便が頼り。人口減と高齢化。Lau は伝統的に有力な首長（例：故 Ratu Sir Kamisese Mara）を輩出した地域。

### 1-4 主要都市と町

| 都市・町 | Division | 役割 |
|---|---|---|
| **Suva** | Central | 首都、政府、議会、USP、PIF事務局、各国大使館、主要港 |
| Nasinu／Nausori／Lami | Central | Suva の衛星都市。Nausori に国内線空港（Nausori Airport） |
| **Lautoka** | Western | 第2の都市「シュガー・シティ」。製糖工場、港 |
| **Nadi** | Western | **Nadi 国際空港**。観光の玄関口。Denarau のリゾート群 |
| Sigatoka | Western | Coral Coast（南岸リゾート）の中心 |
| Ba／Tavua／Rakiraki | Western | サトウキビ・金鉱（Vatukoula）・北西岸の町 |
| **Labasa** | Northern | Vanua Levu 最大の町。サトウキビ |
| Savusavu | Northern | Vanua Levu 南岸の港町 |
| Levuka | Eastern | 旧首都（1874〜1882年頃）、ユネスコ世界遺産 |

### 1-5 気候・災害

- **雨季・サイクロン季：11月〜4月**／乾季：5月〜10月。現地調査・研修日程はこの区分を前提に組む。
- 主なサイクロン：**TC Winston（2016年2月、カテゴリー5）**は南半球観測史上最強級で、死者44人、被害額はGDPの2〜3割規模とされる。ほかに TC Evan（2012）、Harold・Yasa（2020）など。
- 洪水：Ba・Nadi・Rewa 川流域で頻発。Nadi の街は低地で浸水しやすい。
- 気候変動：海面上昇・高潮・海岸侵食で**村ごとの移転（Planned Relocation）**が進む。2014年の Vunidogoloa 村（Vanua Levu）が最初の事例として知られる。政府は移転ガイドライン（2018年）や Climate Change Act（2021年）を整備している。

## 第2章 地名と言葉

> **30秒サマリ**：iTaukei 語の綴りは19世紀の宣教師が作ったもので、**b・d・g・q・c が英語と違う音**になる。これを知らないと地名・人名をほぼ確実に読み間違える。

| 綴り | 発音 | 例 | 読み |
|---|---|---|---|
| **b** | mb（前に鼻音） | Ba／Labasa／Rabuka | ンバ／ランバサ／ランブカ |
| **d** | nd | Nadi／Kadavu | ナンディ／カンダヴ |
| **dr** | ndr | Nadroga／Cakaudrove | ナンドロンガ／ザカウンドロヴェ |

| **c** | th（this の th） | Cakobau／Mamanuca／Moce | ザコンバウ／ママヌザ／モゼ |
| **j** | ch／j に近い | | |

## 第3章 歴史：今を理解するための要点

> **30秒サマリ**：首長国同士が争っていた島々が **1874年に英国へ割譲**され、植民地政府は先住民の土地を保護する一方、サトウキビ労働力として**インドから年季契約労働者（Girmit）**を連れてきた。この「土地は iTaukei、労働と農業経営はインド系」という構造が、1970年の独立後の**民族政治・クーデター・土地リース問題**の根っこにある。

### 3-1 割譲以前

- 約3,000年前にラピタ文化の人々が到来。のちにメラネシア系とポリネシア系（トンガ・サモア）の影響が混ざる。
- 19世紀には **Bau・Rewa・Cakaudrove** などの首長国が覇権を争い、白檀・ナマコ交易、宣教師（メソジスト）、銃器が流入した。
- Bau の首長 **Cakobau** が「Tui Viti（フィジー王）」を名乗るが統治は不安定で、対米債務問題などを抱える。

### 3-2 1874年の割譲と植民地統治

- **1874年10月10日**、Cakobau ら首長が Deed of Cession（割譲証書）に署名し、英国の植民地になる。この日は現在も **Fiji Day**（独立記念日と同日）。
- 1875年に麻疹が流行し、人口の約3分の1が死亡したとされる。
- 初代総督 **Sir Arthur Gordon** の「間接統治」：
  - 首長を通じた統治（Native Administration、のちの大首長会議 GCC の源流）
  - **先住民の土地売却を禁止** → 現在の iTaukei land の枠組み
  - 先住民をプランテーション労働に動員しない → 代わりの労働力として**インド人の年季契約労働**を導入
- それ以前には、ソロモン諸島・バヌアツなどから半ば強制的に連れてこられた労働者（blackbirding）もいた。その子孫のコミュニティは今も残っている。

### 3-3 Girmit（ギルミット）

| 項目 | 内容 |
|---|---|
| 語源 | 英語の "agreement"（契約）がなまったもの。労働者は **Girmitiya** と呼ばれる |
| 始まり | **1879年5月14日**、移民船 **Leonidas 号**が Levuka に到着（約460人）。Nukulau 島で検疫を受けた |
| 規模 | 1879〜1916年に約87航海、**約6万人**がインドから渡航 |
| 契約 | 5年間の労働契約。さらに5年残れば帰国旅費が支給された。約4割が帰国し、多くはそのまま定住 |
| 労働 | 主に CSR社（豪州の製糖会社）のサトウキビ農園。過酷な労働、低賃金、女性への暴力、自殺率の高さなどが記録されている |
| 終焉 | インド国内の反対運動などで1916年に渡航停止、**1920年に全契約が解除** |
| その後 | 契約後は iTaukei 地主から土地を借りる**小作農**としてサトウキビ栽培を担う。商業・専門職にも進出 |
| 記念日 | 🔄 2023年に現政権が **Girmit Day**（5月中旬）を祝日として復活させた |

- **現在への影響**：Indo-Fijian は「土地を所有できない農民」という立場が長く続き、リースの期限切れ（第5章）と政治的な代表権の問題が、民族間の緊張の源になってきた。
- 北インド（ボージュプリー語圏）と南インド（マドラス港経由）の出身者がいたため、Fiji Hindi が共通語として形成された。

### 3-4 独立からクーデター、現在まで

| 年 | 出来事 |
|---|---|
| 1970 | **10月10日に独立**。初代首相は Ratu Sir Kamisese Mara（Lau 出身）。議席は民族別の枠で配分 |
| 1987 | Indo-Fijian 支持の連立政権の誕生後、**Sitiveni Rabuka 中佐が2度のクーデター**。共和制に移行し、英連邦から一時離脱 |
| 1990 | iTaukei の優位を制度化した憲法。Indo-Fijian の国外流出が加速 |
| 1997 | より包摂的な憲法に改正 |
| 1999 | **Mahendra Chaudhry** が初の Indo-Fijian の首相に |
| 2000 | **George Speight による議会占拠（文民クーデター）**。首相らが人質に |
| 2006 | **Frank Bainimarama 海軍司令官のクーデター**。以後、軍事政権 |
| 2009 | 1997年憲法を廃止。大首長会議（GCC）を停止（2012年に廃止） |
| 2013 | **現行の2013年憲法**。民族別の議席を廃止し、全国1区の比例代表制。国民全体を「Fijian」と呼ぶことに |
| 2014・2018 | 選挙で Bainimarama 率いる FijiFirst が勝利 |
| 2022 | 選挙で過半数を取る政党がなく、**Rabuka 率いる People's Alliance・NFP・SODELPA の連立政権**が発足 |
| 2023〜 | GCC の復活、Girmit Day と Ratu Sukuna Day の祝日化。FijiFirst は2024年に解散 |
| 2026 | 🔄 9月に**約20年ぶりの地方（市町）選挙**が予定されていた。**総選挙は2026年後半〜2027年2月上旬**の間に実施予定 |

- 「クーデター文化（coup culture）」という言い方は現地の人が自嘲気味に使うことはあるが、外部の人間が使うのは避けた方がよい。

## 第4章 社会と人々

> **30秒サマリ**：人口は約88.5万人（2017年センサス）。iTaukei が約6割、Indo-Fijian が約4割弱で、ほかに Rotuman、Part-European、中国系、Banaban などがいる。宗教・言語・居住地域がおおむね民族と重なるが、都市部では混ざって暮らしている。

### 4-1 民族構成と呼び方

| グループ | 割合（2007年） | 呼び方の注意 |
|---|---|---|
| **iTaukei** | 約57% | 2010年以降の公式呼称。かつての「Fijian」は国民全体を指すようになった |
| **Indo-Fijian** | 約38% | 「Fijians of Indian descent」とも。「Indian」とだけ呼ぶのは避ける |
| Rotuman | 約1% | Rotuma 島出身者。iTaukei とは別の民族 |
| その他 | 約4% | Part-European（Kai Loma）、中国系、ヨーロッパ系、太平洋諸島系 |

- 🔄 2017年センサスでは**民族別の内訳が公表されていない**。上の数字は2007年のもの。人口移動の傾向として、Indo-Fijian の割合は海外移住によって低下しているとみられる。
- 歴史的な経緯で移住した小さなコミュニティもある：**Rabi 島の Banaban**（キリバスの Banaba 島から1945年に移住）、**Kioa 島の Tuvaluan**、ソロモン系の子孫など。

### 4-2 宗教

- キリスト教 約64%：**メソジスト**が最大（主に iTaukei）。ほかにカトリック、アッセンブリーズ・オブ・ゴッドなど急成長中のペンテコステ系、SDA（セブンスデー・アドベンチスト）。
- ヒンドゥー教 約28%、イスラム教 約6%（主に Indo-Fijian）。
- **メソジスト教会は iTaukei 社会で政治的な影響力も大きい**。日曜日は村の活動が礼拝中心になる。

### 4-3 村と都市

- 都市人口はおよそ56%（2017年）。Suva から Nausori にかけての回廊に集中している。
- 都市周辺には**インフォーマル居住地（squatter settlements）**が広がる。リースが切れた Indo-Fijian 農民や、地方から出てきた iTaukei が住んでいる。
- 村（koro）は mataqali・yavusa といった血縁集団を単位にしており、首長・教会・村代表を中心に動く（第6章）。
- 海外への出稼ぎ・移住先は、豪州・NZ・米国・カナダ。最近は豪州の労働者受け入れ制度（PALM scheme）も大きい。

## 第5章 土地と海の制度

> **30秒サマリ**：国土の約9割は **iTaukei land** で、**mataqali などの共同体が所有し、売ることはできない**。使う場合は **TLTB（iTaukei Land Trust Board）**を通じたリースになる。Freehold（自由保有地）と State land（国有地）は合わせて1割程度。沿岸の海にも **qoliqoli** という慣習的な漁業権がある。**開発・研究・データ収集で土地や海に関わるときは、「誰の土地・海か」と「誰の同意が要るか」が出発点になる。**

### 5-1 土地区分

| 区分 | 割合（目安） | 内容 |
|---|---|---|
| **iTaukei land**（旧 Native land） | 約87〜91% | 慣習的な集団が所有。**譲渡不可**。TLTB がリースを管理 |
| **Freehold land** | 約6〜8% | 割譲前に外国人へ売られた土地。売買可能。都市部やリゾートに多い |
| **State land**（旧 Crown land） | 約3〜4% | 国有地。Ministry of Lands が管理 |

- 割合は資料によって違う（TLTB は約91%と説明している）。提案書などでは「約9割」と書き、出典を添えるのが安全。
- **外国人による土地取得**には規制がある（🔄 Land Sales Act の改正などで変化しうるので、実務では要確認）。

### 5-2 慣習的な所有の単位

```
Vanua（地域共同体）
 └ Yavusa（ヤヴサ：共通の祖先を持つ大きな氏族）
    └ Mataqali（マタンガリ：土地所有の基本単位となる氏族）
       └ Tokatoka（トカトカ：拡大家族）
          └ 世帯
```

- **土地を所有する単位として最も一般的なのは mataqali**。ただし地域によっては yavusa や tokatoka が所有している場合もある。
- 所有者の登録：**VKB（Vola ni Kawa Bula）**＝ iTaukei の血統登録簿。生まれた人は父系で mataqali に登録され、土地からの収益分配の権利もこれに基づく。
- 土地の境界と所有者は、植民地時代の **Native Lands Commission**（現 iTaukei Lands and Fisheries Commission）の調査で確定された。ただし、**慣習的な境界と登録上の境界が食い違う紛争**は今もある。
- 首長は土地の「所有者」ではなく、共同体の代表者。土地の利用には**共同体の合意**が必要で、リースには TLTB が所有集団の成人メンバーから一定割合以上の同意を得る手続きがある（🔄 具体的な割合は要確認）。

### 5-3 TLTB とリースの仕組み

- **TLTB（iTaukei Land Trust Board）**：1940年に設立（旧 NLTB）。所有者に代わってリースを交渉・管理し、地代を徴収・分配する。
- リースの種類：農業、住宅、商業、観光、工業など。期間は用途によって異なり、最長99年。
- 地代の分配：かつては首長層に優先的に配分されていたが、**2010年代の改正で mataqali のメンバー全員に均等に分配**されるようになった。
- **ALTA 問題**：農地賃貸法（ALTA、1976年）による**30年リースが1997年頃から次々に満期**を迎え、更新されなかった Indo-Fijian のサトウキビ農家が土地を失った。都市周辺のインフォーマル居住地が広がる一因になり、民族間の緊張の象徴になった。
- **Land Use Act（2010年）**：所有者が土地を「ランドバンク」に預け、政府経由で貸し出す仕組み。所有権は手放さない。

### 5-4 qoliqoli（慣習的漁業権区域）

- 沿岸の礁湖・サンゴ礁の漁場は、約410の qoliqoli に区分・登録されている。
- 海底の所有権は国にあるが、**漁業権は慣習的な所有集団（yavusa・mataqali など）に属する**。商業漁業には許可と所有者の了承が必要。
- 地域主導の海洋保護の取り組み（LMMA：地域管理海洋区）が広がっており、**tabu（一時的な禁漁区）**を村が設定することもある。
- 約410のうち一部は乱獲状態と指摘されている。

### 5-5 開発・研究・データ収集の実務ポイント

- **同意の順序**：政府（関係省庁・District Officer）→ Provincial Office（Roko Tui）→ 村（Turaga ni Koro、首長）→ 土地・漁業権の所有集団。村に入るときは **sevusevu から**（第9章）。
- **FPIC（自由意思による、事前の、十分な情報に基づく同意）**の考え方が国際機関・ドナーの案件では標準。
- 衛星画像やGISで描いた境界は、**慣習上の境界と一致しないことがある**。地図を公開するときには、紛争を誘発しないよう注意する（境界線を引くこと自体が政治的な行為になりうる）。
- 土地や漁場の情報、村ごとのデータは、共同体にとってセンシティブな情報。**データの扱い（誰が所有し、誰に共有するか）**を事前に合意しておく。

## 第6章 統治と行政区分

> **30秒サマリ**：国の政治は**一院制の議会（55議席、全国1区の比例代表制）**と首相による議院内閣制。行政は**政府のライン（4 Division → District）**と **iTaukei 行政のライン（14 Province → Tikina → Koro）**が並んで動いている。さらに首長制という伝統的な権威が重なる。**「誰が決めるか」はテーマによって違う**。

### 6-1 国の政治制度

- 共和制。大統領（元首、議会が選出、儀礼的な役割）と首相（行政の長）。
- 議会：**一院制、55議席**。全国を1つの選挙区とする**非拘束名簿式の比例代表制**（得票率5%の足切りあり）。任期4年。2013年憲法で上院は廃止。
- 主な政党（🔄）：People's Alliance（Rabuka 首相）、NFP（National Federation Party、Indo-Fijian 系の老舗政党）、SODELPA（iTaukei 系）、Unity Fiji など。FijiFirst（旧与党）は2024年に解散した。
- 🔄 **総選挙は2026年後半〜2027年2月上旬の間**に実施予定。政権の枠組みは選挙後に変わりうる。

### 6-2 二重の行政

| 政府のライン | iTaukei 行政のライン |
|---|---|
| 首相府・各省庁 | Ministry of iTaukei Affairs／iTaukei Affairs Board |
| **Division（4）**：Commissioner が統括 | **Province（Yasana、14）**：Provincial Council（Bose ni Yasana）と執行責任者 **Roko Tui** |
| **District**：District Officer（DO） | **Tikina**（郡、複数の村のまとまり）：Mata ni Tikina |
| 市町（13）：Municipal Council | **Koro（村）**：**Turaga ni Koro**（村代表、行政上の窓口） |
| 対象：国民全体 | 対象：主に iTaukei の村落社会 |

- **Division** は開発計画・災害対応・統計の地域区分としてよく使われる。
- **Province** は iTaukei 社会の単位だが、統計（センサス）の集計単位としても使われる。どの Province がどの Division に入るかは付録Cを参照。
- **Rotuma** は14の Province とは別枠の属領で、Council of Rotuma が自治的に運営している。
- 村の中のインド系集落（settlement）や都市は、iTaukei 行政の外にある。

### 6-3 伝統的な権威

- **首長制**：各地の首長は世襲の称号を持つ（例：Bau の **Vunivalu**、Rewa の **Roko Tui Dreketi**、Cakaudrove の **Tui Cakau**、Lau の **Tui Nayau**）。
- **3つの連合体（Matanitu）**：首長の連合体で、地域のまとまり方を理解する鍵になる。

| 連合体 | 主な地域 |
|---|---|
| **Kubuna** | Bau を中心とした本島東部・北東部（Tailevu、Naitasiri、Ra の一部など） |
| **Burebasaga** | Rewa を中心とした本島南部・西部と Kadavu など |
| **Tovata** | Vanua Levu・Taveuni（Cakaudrove、Macuata、Bua）と Lau |

- 本島西部はこの3つの連合体の枠に収まりにくく、独自性が語られることがある（第1章）。
- **大首長会議（GCC：Bose Levu Vakaturaga）**：植民地時代から続く首長の最高協議体。2012年に廃止されたが、**2023年に現政権が復活**させた。iTaukei の利益に関わる問題について発言力を持つ。

### 6-4 地方自治体

- 13の市町（Municipal Council）がある。Suva と Lautoka が「市（City）」で、ほかは「町（Town）」。
- 2009年以降は選挙がなく、政府が任命した特別行政官が運営していた。🔄 **2026年9月に約20年ぶりの選挙**（13市町、141議席）が予定されていた。実施の有無と結果を確認すること。
- 市町の区域外（村・農村部）は、District Officer や、Rural Local Authority などが管轄する。

### 6-5 意思決定マップ：誰に、どの順番で話を通すか

| テーマ | 主な窓口・決定者 |
|---|---|
| 国の政策・許認可 | 担当省庁（Permanent Secretary） |
| 地域の開発・災害対応 | Commissioner（Division）、District Officer、NDMO |
| 村での活動・調査 | Provincial Office（Roko Tui）→ Turaga ni Koro → 首長 → 村の会議 |
| 土地・リース | TLTB と所有集団（mataqali） |
| 漁場 | Ministry of Fisheries と qoliqoli の所有集団 |
| 教育機関との連携 | Ministry of Education、学校の管理者（宗教団体系の学校も多い） |
| 宗教・コミュニティ | 教会（メソジストなど）、寺院・モスクの団体 |

## 第7章 経済と産業

> **30秒サマリ**：太平洋島嶼国の中では経済規模が大きく、多様化が進んでいる。柱は**観光（最大）・海外送金・砂糖（縮小傾向）・水産・ミネラルウォーター・カヴァ**。通貨はフィジー・ドル（FJD）。

| **インフラ** | Fiji Airways（国営航空）、Nadi 国際空港、Suva・Lautoka 港。海底ケーブルによる通信 |

- 🔄 GDP、成長率、物価、為替などの数値は、Reserve Bank of Fiji や Fiji Bureau of Statistics の最新データを使う。

## 第8章 地域ハブとしてのフィジーと国際関係

> **30秒サマリ**：Suva は**太平洋島嶼地域の「首都」的な存在**。地域機関・大学・国連・各国大使館が集まり、フィジーは地域の外交・教育・物流の中心になっている。

- **地域機関**：
  - **太平洋諸島フォーラム事務局（PIFS）**：Suva に本部
  - **南太平洋大学（USP）**：本部とメインキャンパス（Laucala）が Suva。12か国が共同で運営
  - **太平洋共同体（SPC）**：本部は Nouméa だが、Suva に最大級の拠点
  - ほかに国連の多国間オフィス、地域の NGO・ドナー事務所
- **国内の大学**：Fiji National University（FNU）、University of Fiji。
- **外交**：「Friends to all, enemies to none」を掲げる。豪州・NZとの関係が深く、中国・米国・インド・日本などとの関係も重視している。COP23（2017年）の議長国を務め、気候変動外交で発言力がある。
- **日本との関係**：
  - 在フィジー日本国大使館、**JICA フィジー事務所**
  - 太平洋・島サミット（PALM）
  - 海外協力隊の派遣、USP の ICT センターへの協力、防災・気象分野の支援など

## 第9章 現場の作法とコミュニケーション

> **30秒サマリ**：村に入るときは **sevusevu で始めるのが鉄則**。**帽子・サングラスを外す、頭に触れない、肩と膝を隠す、日曜日は控えめに**。合意は talanoa の場で時間をかけて作られる。政治・民族・土地・クーデターの話題は自分から持ち出さない。

### 9-1 村を訪問するとき

1. **事前に連絡**：Turaga ni Koro か村の関係者に、訪問の目的と日時を伝えておく。
2. **sevusevu**：ヤンゴナの根（waka）を持参し、村の代表に渡して訪問の目的を述べる。受け入れの儀礼を経て、初めて村の「客」になる。
3. **服装**：男女とも肩と膝を隠す。sulu を持っていくと便利。
4. **帽子とサングラスを外す**：村の中では首長だけが頭に何かを着けるものとされる。
5. **頭に触れない**：頭は神聖な部位。子どもの頭を撫でるのもNG。
6. **人の前を通るとき**：座っている人の前は、身をかがめて「tulou」と言いながら通る。
7. **日曜日**：教会と休息の日。大きな音、作業、遊泳などは控える。
8. **贈り物とお返し**：もてなしを受けたら感謝を伝え、適切なお返しをする。
9. **写真撮影**：人や儀式を撮る前に必ず許可を得る。

### 9-2 カヴァ（yaqona）の場

- 勧められたら、一回手を打って「Bula」と言い、一気に飲み干す。その後、手を3回打つ。
- 量は「low tide（少なめ）」「high tide（多め）」と頼める。
- 首長や長老が先に飲む。順番を守る。

### 9-3 コミュニケーションの特徴

- **talanoa**：上下関係を和らげた車座の対話で、合意を作る。一度の会議で結論を出そうとせず、時間をかける。
- **直接的な「No」を言いにくい文化**：「Io（はい）」でも同意ではない場合がある。曖昧な返事は、反対や困惑のサインかもしれない。
- **Fiji time**：時間感覚がゆったりしている。遅れても責めない。ただし公式行事は時間通りのこともある。
- **kerekere**：頼まれたら分け合う慣行。物の貸し借りの感覚が日本と違う。
- 意思決定には**首長・長老・教会・行政**それぞれの了承が必要な場合が多い。

### 9-4 扱いに注意すべき話題と言い換え

| 避ける言い方 | 推奨される言い方・態度 |
|---|---|
| 「Fijian と Indian」 | 「iTaukei と Indo-Fijian」。国民全体は「Fijians」 |
| 「原住民」「土人」「native」 | 「先住系（iTaukei）」 |
| 「クーデターの国」「coup culture」 | 事実として年号と経緯を述べるにとどめる |
| 土地問題でどちらかの側に立つ | 制度と経緯の説明にとどめ、評価を加えない |
| 宗教の比較・優劣 | 多宗教の共存として紹介する |
| 政治家や首長への批判 | 外部の人間は控える。特に村の中では |
